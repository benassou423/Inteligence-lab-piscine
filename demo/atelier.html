Le principe de l’apprentissage · 45 secondes

Dans quel sens faut-il changer un nombre ?

Le gradient mesure comment le résultat change lorsque l’on modifie une valeur. Notre outil de calcul automatique des gradients, appelé autograd, le calcule en remontant les opérations, puis nous comparons le résultat avec PyTorch, une bibliothèque de calcul.

Un calcul que l’on peut vérifier à la main

y = x² + 2x + 1

Résultat réellement calculé

Choisir x puis lancer le calcul.

À x = 3, y vaut 16 et le gradient vaut 8. Une petite hausse de x augmente y environ huit fois plus vite.

Du texte aux nombres · 45 secondes

Le modèle lit des tokens

Un token est un morceau de texte représenté par un numéro. Le BPE apprend à fusionner les morceaux les plus fréquents. Le texte doit pouvoir être reconstruit exactement, avec ses accents et sa ponctuation.

Les deux vocabulaires appartiennent à deux modèles différents. On ne peut pas les interchanger.
