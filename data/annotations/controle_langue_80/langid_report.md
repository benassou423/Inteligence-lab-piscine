# Contrôle du filtre de langue

Méthode : classement automatique de 80 extraits couvrant les sept sources ; 63 français, 10 sans prose française exploitable, 7 mélangés. Aucun contrôle manuel indépendant n’est attesté.

Précision pondérée relative aux classes automatiques : 99,69 %. Rappel : 96,96 %. La variation des 17 cas limites donne une précision de 99,56 à 99,80 % ; il s’agit de sensibilité aux labels, pas d’un intervalle de confiance sur une vérité humaine. Les 46 extraits tronqués ne caractérisent pas leurs livres entiers.

Les données de ce dossier conservent les scores, poids, IDs, hashes et classes pour reproduire les calculs. Les textes sources et les passages cités restent dans le dossier de travail, hors de cet export.
