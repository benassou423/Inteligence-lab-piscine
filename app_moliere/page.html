Bienvenue chez Molière

Cette application fait parler un petit modèle de langage dans le style du théâtre de Molière. Elle fonctionne entièrement sur votre ordinateur.

Au premier lancement, elle doit télécharger le modèle (240 Mo), une seule fois, depuis la page de publication du projet sur GitHub (benassou423/Inteligence-lab-piscine). Le fichier est vérifié par empreinte avant d'être utilisé.
